# ADR-REFACTOR-16 · 拖拽可以，落盘要过三道闸

- 状态：已实施（R8.9，D10a 的交互 + D12 的提交语义）
- 日期：2026-11-13
- 关联：ADR-REFACTOR-15（面积重排的算术底座）、`scripts/assembly.py`、
  `scripts/check_assembly.py`、`console/static/areas.js`

## 背景

R8.5–R8.8 把"面积 → 库容"的算术做通了，但交互还是"勾模板 → 算法排"。方案书 D10a 要的是
**用户自己拖**，D12 要的是 **DRAFT → 校验 → 显式提交**。

这两条合在一起意味着：拖动过程中**一个字节都不能写**，只有"校验过、且校验的就是这份草稿"
才允许落盘。技术难点不在拖拽，在**事务边界**。

## 决策一：拖拽只改内存，落盘走令牌

```
拖动  → A.draft.moves = {template: [dx, dz]}   内存，不请求
松手  → POST /api/areas/plan  → 服务端返回权威 rect + token
校验  → 同一接口，返回 issues；有 issue 就不发 token 的"可提交"状态
提交  → POST /api/areas/commit {enabled, moves, token}
```

令牌是 `sha256(moves + 每个矩形最终位置)[:16]`。**只对用户意图取摘要，不对算法结果取**——
否则排布算法改一点点，所有旧令牌都失效，用户刚校验完就被告知过期，体验更糟且没有额外安全性。

服务端收到提交时**重算令牌**再比对。对不上就是"校验的是 A、提交的是 B"，直接 `STALE_PLAN`。
这条闸挡的是拖完再拖一格就点提交的常见操作。

## 决策二：三道闸，外加一次复核

| 闸 | 拒绝码 | 拦的是 |
|---|---|---|
| 没令牌 | `NEED_VALIDATE` | "拖完直接存" |
| 令牌不符 | `STALE_PLAN` | 校验后草稿又变了 |
| 几何不过 | `GEOMETRY_INVALID` | 拖进货架/月台/墙外 |

通过之后才写 `config/layout_spec_assembly.json`，然后**再校验一遍写出的 spec**
（`recheck`）——因为"写成功"只证明磁盘可写，不证明写的东西是对的。

## 决策三：必须跑两个校验器（这一条是被门抓出来的）

第一版 `assembly.check()` 只跑 `spec_layout.py`，结果"把收货区拖进货架带"拿到 **0 issue**，
越界草稿被写进了盘。

原因：`spec_layout` 的 L2/L3 的 `rects` 只装 racks / docks / stations，**不含 areas**。
areas 归 `spec_areas.py` 的 L23–L26 管。只跑一个，等于 areas 完全没有防线。

这是"校验器覆盖范围 ≠ 语义"的典型：**校验没报，不代表东西没错**。现在两个都跑，合并 issue。

## 决策四：交互上"谁先命中谁拿走"

画布上已经有一种拖拽（平移视图）。加第二种（拖功能区）时，`mousedown` 先问功能区要不要接：
接了就不进 pan 分支。否则用户一拖区，整张图跟着跑，看起来像 bug 但其实是两套事件打架。

拖动时同时画**原位置虚影**（灰虚线）和**现位置实线**，否则用户看不出挪了多远，也没法拖回去。

## 门（`ASSEMBLY_COMMIT_OK`）

四条用例，每条都同时断言**返回值**与**磁盘状态**：

1. 没令牌 → `NEED_VALIDATE`，且目标文件哈希不变；
2. 令牌过期 → `STALE_PLAN`，且文件不变；
3. 越界（收货区下拖 52 m 进货架带）→ 3 条 L23，`GEOMETRY_INVALID`，且文件不变；
4. 合法 → 真的写出，写出的 spec 重新校验 0 issue。

自检 5 条反例：`commit_ok`、`no_token_rejected`、`stale_rejected`、
`recheck_catches_overflow`、`move_too_far`。

第 3 条之所以要断言"文件不变"：**拒绝本身很好伪造**（返回一句错误就行），
真正的证据是盘上没有新东西。所以每次拒绝都对目标文件做前后哈希比对。

## 未做

  API 在快照/白名单里、GLB 一致）+ 人工点击。没有做浏览器自动化。
- **月台不可拖**：月台锚南墙（ADR-15 决策一），本轮只允许拖功能区。
- **拖动时的实时碰撞高亮**：现在是"松手才校验"，不是"拖到一半就变红"。
- **x 方向**：`bays` 仍写死（与 ADR-15 同一笔账）。
