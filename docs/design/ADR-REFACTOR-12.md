# ADR-REFACTOR-12 · 3D 产出目前**不是**字节可复现的——所以锚点只能锚结构

- 状态：已查明、已绕开、待修（R8.4 第一件）
- 方案依据：§10 金标准重冻纪律、§12.6 `3D_GOLDEN_OK`、D11（counts + GLB 哈希双锚）
- 相关：ADR-REFACTOR-11（R8.2 派发与探针）

## 背景：本文档否掉了我自己上一轮的一个结论

R8.2 里我写过"默认构建的 `build_report.json` 与 `dc_preview.glb` 哈希逐字节不变"。
前半句站得住，**后半句是空的**：`build_dc.py` 根本不写 `dc_preview.glb`——那是
`export_glb.py` 的产物。我对比的是"没人动过的旧文件"，等于证明"这个文件没被改"，
与"构建是否可复现"无关。这是同一类错误（看着有证据，其实没测），必须自己先说。

## 实测：GLB 两次运行不相同

同一份数据、同一台机器、同一 Blender（5.2.41），连跑两次 `build_dc` + `export_glb`：

| 场景 | JSON chunk | 二进制 | 字节数 | 结构（mesh/primitive/顶点/材质） |
|---|---|---|---|---|
| 默认布局 | **完全相同** | 1864 / 665196 字节不同 | 1211380 = 1211380 | 完全相同 |
| 带 rack_type | 差 1 个未被引用的 accessor | 不同 | 1185888 vs 1185036 | 完全相同 |

进一步定位：

- 默认场景的差异**全部落在 7 个索引缓冲**（`target=34963`，uint16，各 720 字节）里；
  把每个缓冲的字节**排序后比较，完全相同** → 只是三角化顺序变了，几何一点没动。
- 带机理场景的差异是"多/少一个**未被任何 mesh 引用**的 accessor"——同样不影响几何。

结论：**几何是确定的，序列化不是。** 直接对文件取 sha256，等于把"这次运行怎么调度
线程/怎么分配数据块"写进金标准。

## 决策一 · 锚结构，不锚字节

`check_asset_dispatch.py --typed-build` 的锚点改为：

```
counts（7 类派发数 / fallback / pallets / objects / meshes）
+ layout_sha256（布局内容）
+ glb_structure（mesh 名 + primitive 数 + 顶点数 + 材质名，排序后取哈希）
```

`glb_structure` 在默认与带机理两种场景下都稳定（实测两次运行相同）。它能抓的东西
恰好是金标准该抓的：**母版被换、数量对不上、某类货架又变回横梁式**。抓不到的只有
"顶点坐标被改了但数量不变"——这一层由 `rack_mesh_probe` 的 `geom_sha`（顶点坐标排序
哈希）覆盖，两者互补。

`glb_bytes` 仍记录在报告里，但**不参与比对**，只作为"这次是不是那个 852 字节的岔路"的线索。

## 决策二 · 负对照先跑通，再谈冻结

`--self-test` 里加了三条：

- `anchor_matches`：同一份摘要自比必须通过；
- `anchor_count_drift`：把派发数从 `{a:1}` 改成 `{a:2}`，必须判红；
- `anchor_glb_drift`：把结构指纹换掉，必须判红。

没有这三条，"双锚"就是一句自我安慰。`--freeze` 需要人显式加参数，且冻结前必须先跑
一次不冻结的比对（两次运行一致）才允许写盘——顺序写进 `ADR-11` 的操作流程里。

## 决策三 · 字节级复现列为 R8.4 的第一件事（不藏）

要修的是这两处，都不难但都不该在本轮顺手改——它们会让所有 3D 产物同时变一次：

1. **三角化顺序**：`bmesh` 建面后没有做确定性排序，`export_apply=True` 时的三角化顺序
   随内部哈希走。可行做法：导出前对每个 mesh 做一次 `sort_elements`（顶点/面按
   坐标+拓扑排序），或改用固定 `PYTHONHASHSEED` + 关闭并行法线计算后复测。
2. **多余 accessor**：导出后做一次"未被引用的 accessor / bufferView"清理，或查明
   Blender 导出器在什么条件下会留下它。

两者都修完之后，`3D_GOLDEN_OK` 才能真的用字节哈希，方案书 D11 的"GLB 哈希双锚"才
名副其实。在那之前，本文档的"结构指纹"是**诚实的临时替代**，不是等价物。
