# Code of Conduct

This is a small research repository. Be respectful, assume good intent, and
keep discussion focused on the work.

- No harassment, discrimination, or personal attacks.
- Critique the data and the method, not the person. A failing validator is
  useful information, not a failure of its author.
- Do not paste real customer data, credentials, or private keys into issues,
  PRs, config files or test fixtures.

Maintainers may edit or remove contributions that violate these rules.
Report problems privately via a GitHub issue marked `conduct`.
