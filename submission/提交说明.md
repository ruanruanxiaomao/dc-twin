## 3. 作品简介（可直接复制）

配送中心数字孪生 · DC Twin Studio —— 从一张布局图纸，到可仿真、可算账、可定制的运营孪生。

作品以一区域仓 W 加三前置仓 F1/F2/F3 为对象：四层 JSON 配置经 `spec_layout.py` 展开并校验，
生成 4 个仓库、196 组货架、441 个库位与 21 台 AGV；闭环任务驱动的 8 向 A* 规划出
`HOME→取货→交付→回位` 路径并做线段级穿货架校验；tick 级离散事件仿真实现持续订单到达、
在线派单、9 态车辆状态机、电量与充电、故障重派和 L1 时空预约；事件溯源账本把每一次运行换算成
收入、变动成本、固定分摊、单均成本、盈亏平衡点与 ±20% 敏感性；Blender 5.2 程序化生成
`.blend`、GLB、10 张 1920×1080 渲染图与 MP4 闭环动画。

作品页用自研的零依赖 3D 投影渲染器，把 196 组立体货架按深度排序与光照着色，
可拖拽旋转 / 缩放 / 跟随车辆，动画由 `data/paths.jsonl` 的 5421 条真实关键帧驱动；
同时提供项目全景（六环节数据链、57 个真实交付物、数据契约）、模型与渲染（在线播放动画、
下载 `.blend` / `.glb` / `.mp4`）、8 场景 KPI、逐条 A/S/F 验收明细、27 项 KPI 定义与真实事件流。
定制能力包括可视化 2D 布局编辑器（拖拽 + 背景描图两点标定）、DXF 与 LIF 草稿导入、
自定义场景「校验 → 试算 → 保存 → 运行」闭环，以及只读优先的 WMS 适配器框架。

全部指标可独立复算：既有验收 A1–A40 40/40，真仿真 S1–S9 共 22 项检查、盈亏 F1–F7 共 54 项检查、
pytest 41 项用例全部通过；GitHub 开源对照已逐项核实许可证，并严格区分代码衍生与概念参照。

6. 把本作品页的在线链接一并填入作品地址栏。

## 5. 分享前隐私检查（表单红字要求）

表单明确写着「分享前请务必确认对话中不含个人隐私、商业机密等敏感信息」。项目侧已做过的检查：

- 源码、文档、配置与作品页数据快照中**无个人绝对路径**（构建脚本内置断言，扫描 `C:/Users/...` 形式路径，0 命中）。
- `config/integrations.json` **不含任何密钥**，只保存环境变量名（如 `DC_WMS_TOKEN`）。
- 示例场景、渲染图、损益表均为合成数据，无真实企业订单 / 客户信息。
- 第三方资产已在 `THIRD_PARTY_NOTICES.md` 登记许可证，无未授权素材。

**仍需你本人在对话记录里逐条确认**：姓名、学号、手机号、家庭住址、本机用户名与路径、
截图里的窗口标题 / 文件列表、任何账号或令牌。若有，建议新建一个只包含创作过程的精简对话再分享，
或分享前删掉敏感轮次。

2. **实时孪生**拖动 3D 场景换个角度，看 21 台 AGV 沿真实关键帧做闭环作业；切「俯视平面」「Blender 渲染」对照。
3. **项目全景**快速核对六环节脚本与 57 个交付物，确认这不是演示动画而是完整工程。

5. **场景实验室 / 运营盈亏 / 验收证据**核对 KPI、账本分录与逐条 PASS 记录。

## 9. 诚实声明

- 作品页 3D 是**浏览器端软件 3D 投影渲染**（自研 Canvas 2D 渲染器，含面光照与深度排序），
  **不是 Blender 实时视口**；Blender 的高保真成果在渲染图、`.blend` 与 GLB 中，页面已标注。
- 场景 KPI 与 3D 动画**不是同一次运行**：动画来自主链 21 单闭环关键帧，KPI 来自各场景 tick 仿真报告，页面已标注。
- 所有价格为 `prices_source=demo` 演示值，1 小时班次下各场景均亏损，**禁止用于真实经营决策**。
- LIF 是自研草稿格式，**非 VDA 5050 认证**；DXF 导入只处理 ASCII 子集，复杂图纸转人工描图（G2）。
- 布局编辑器为 2D，**暂无 3D 拖拽预览**；碰撞口径是采样验证 + 预约表复核，不宣称形式化证明。
- 静态页只做参数编排与草稿导出；真正跑仿真需在项目目录执行 §10 的 CLI。
