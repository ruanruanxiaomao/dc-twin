## 3. 作品简介（可直接复制）

配送中心数字孪生 · DC Twin Studio —— 从一张布局图纸，到可仿真、可算账、可定制的运营孪生。

作品以一区域仓 W 加三前置仓 F1/F2/F3 为对象：四层 JSON 配置经 `spec_layout.py` 展开并校验，
生成 4 个仓库、196 组货架、441 个库位与 21 台 AGV；tick 级离散事件仿真驱动持续订单到达、
在线派单、9 态车辆状态机、电量与充电、故障重派和 L1 时空预约；事件溯源账本把每一次运行换算成
收入、变动成本、固定分摊、单均成本与盈亏平衡点；Blender 5.2 程序化生成 `.blend`、GLB、
10 张渲染图与 MP4 动画。

定制能力包括可视化 2D 布局编辑器（拖拽 + 背景描图两点标定）、DXF 与 LIF 草稿导入、
自定义场景「校验 → 试算 → 保存 → 运行」闭环，以及只读优先的 WMS 适配器框架。

全部指标可独立复算：既有验收 A1–A40 40/40，真仿真 S1–S9 共 22 项检查、盈亏 F1–F7 共 54 项检查、
pytest 41 项用例全部通过；GitHub 开源对照已逐项核实许可证，并严格区分代码衍生与概念参照。
技术栈：Python 标准库、Blender 5.2 (bpy)、Canvas 2D、零后端静态发布。

## 4. 「05 WorkBuddy 创作对话记录」分享链接怎么拿

1. 打开创作这个作品的 WorkBuddy 对话，点击页面**右上角「分享」**按钮。
2. 选择要分享的对话（建议只勾选本作品相关对话）。
3. 在底部工具栏选择 **「链接」**，复制生成的地址。
4. 粘贴到活动表单第 05 项。
5. **提交前重新打开一次链接**，确认评审人员可以正常访问（最好用无痕窗口 / 未登录状态验证）。
6. 把本作品页的在线链接一并填入作品地址栏。

## 5. 分享前隐私检查（表单红字要求）

表单明确写着「分享前请务必确认对话中不含个人隐私、商业机密等敏感信息」。项目侧已做过的检查：

- 源码、文档、配置中**无个人绝对路径**（已全量扫描 `C:/Users/...` 形式路径，0 命中）。
- `config/integrations.json` **不含任何密钥**，只保存环境变量名（如 `DC_WMS_TOKEN`）。
- 示例场景、渲染图、损益表均为合成数据，无真实企业订单 / 客户信息。
- 第三方资产已在 `THIRD_PARTY_NOTICES.md` 登记许可证，无未授权素材。

**仍需你本人在对话记录里逐条确认**：姓名、学号、手机号、家庭住址、本机用户名与路径、
截图里的窗口标题 / 文件列表、任何账号或令牌。若有，建议新建一个只包含创作过程的精简对话再分享，
或分享前删掉敏感轮次。

## 7. 评审 3 分钟导览

1. **总览**：关键数字与四层能力；右侧是 Blender 总览渲染图。
2. **实时孪生**：21 台 AGV 按 `data/paths.jsonl` 的**真实关键帧**做闭环作业；可拖动时间轴、切倍速。
3. **场景实验室**：8 个场景的完成单量 / 吞吐 / 充电 / 重派 / 最小间距；右侧可编排自定义场景并导出 JSON。
4. **运营盈亏**：损益瀑布、盈亏平衡、9 个运行利润对比、敏感性区间。
5. **布局编辑**：拖拽分区与待命位、加货架排 / 月台门、上传平面图两点标定、导出草稿 JSON。
6. **验收证据**：A/S/F 验收计数、GitHub 许可证对照、8 张渲染图、已知限制。
7. **提交材料**：简介复制、分享链接步骤、隐私清单、本地复现命令。

## 8. 诚实声明

- 作品页的**场景 KPI 与动画不是同一次运行**：动画来自主链 21 单闭环关键帧，KPI 来自各场景 tick 仿真报告，页面已标注。
- 所有价格为 `prices_source=demo` 演示值，1 小时班次下各场景均亏损，**禁止用于真实经营决策**。
- LIF 是自研草稿格式，**非 VDA 5050 认证**；DXF 导入只处理 ASCII 子集，复杂图纸转人工描图（G2）。
- 碰撞口径是采样验证 + 预约表复核，不宣称形式化证明。
- 静态页只做参数编排与草稿导出；真正跑仿真需在项目目录执行 §9 的 CLI。

## 9. 本地完整复现（可选）

```bash

python run.py --scope scenarios        # 主链 21 步

python scripts/validate_sim.py         # S1–S9
python scripts/validate_pnl.py         # F1–F7
python -m pytest -q                    # 全量测试
python scripts/build_submission.py     # 重建本页数据快照
python -m dc_twin.cli serve            # 本地控制台（运营 / 场景面板）
python scripts/scenario_tools.py list  # 自定义场景
```
